# Contributing

## Where to get help

Open a GitHub issue on this repository and tag it as a question. There's no chat channel yet. One maintainer reads every issue.

## What counts as a contribution

Code, bug reports, documentation fixes, and answering other people's issues all count.

## Reporting a bug

Open an issue using the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md). Found a security vulnerability instead? Don't open an issue for it. See [`SECURITY.md`](SECURITY.md).

## Proposing a change

Small changes can go straight to a pull request. Anything that changes behavior a user would notice, like a default, a command, or the on-disk format, should start as an issue using the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md) so it gets discussed before you write code nobody ends up merging.

## Submitting a pull request

Branch naming and commit message format are in [`AGENTS.md`](AGENTS.md) section 4. Tests and lint have to pass, and a pull request should hold one change. If you're claiming a performance improvement, include numbers from an actual run, not an estimate.

## Scope of issues and pull requests

Issues and pull requests are for bugs, features, and questions about turnbreak itself. General questions about the agent you're running turnbreak with belong in that agent's own support channel.

## Licensing

This project is MIT licensed, and by submitting a pull request you agree your contribution is too. There's no Contributor License Agreement and no sign-off requirement. That's the right amount of friction for a project this size, and it'll get revisited if the license ever needs to change.

## AI-assisted contributions

Turnbreak's own codebase was built with agent assistance, so this project doesn't ban the practice elsewhere either. If you use one:

- Say so in the pull request, and name the tool.
- Review its output yourself before asking a human to. Treat the tool's work as a first draft, not a finished change.
- Don't credit the tool as an author, co-author, or committer on the commit.
- Answer review comments yourself.
- Keep at most one AI-assisted pull request open at a time.

## Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), in [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). Report concerns through the contact listed there.
